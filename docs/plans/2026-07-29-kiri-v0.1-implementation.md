# kiri v0.1 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build and publish the first native macOS foundation of kiri with region capture, clipboard export, and a recoverable local capture library.

**Architecture:** A Swift Package contains an AppKit/SwiftUI executable and a testable KiriCore library. Platform UI coordinates capture sessions while KiriCore owns geometry, asset metadata, and durable local storage so image, video, GIF, and long-image assets can share one library.

**Tech Stack:** Swift 6, SwiftUI, AppKit, ScreenCaptureKit, CoreGraphics, XCTest, Swift Package Manager
