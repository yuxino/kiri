# kiri v0.1 completion design

## Scope

This milestone finishes the still-capture experience before work begins on
video, GIF, or scrolling capture. It adds text and mosaic annotations,
configurable shortcuts, adjustable selections, a pixel loupe, and better
mixed-display handling. Apple signing and notarization remain a release
operation because they require credentials that do not belong in the
repository.

## Editor

The annotation canvas keeps a non-destructive list of marks. Text is inserted
through a small prompt and stored as a string plus anchor point. Mosaic is
stored as a rectangle; preview and export use the same block-size rules so the
saved image matches the editor. Pen, rectangle, arrow, text, and mosaic all use
one explicit view-to-image coordinate transform.

Text defaults to a readable white semibold label with a dark translucent
backplate. Mosaic uses a nearest-neighbor downscale/upscale operation on only
the chosen rectangle. Undo removes the latest mark regardless of type.

## Shortcut

`CaptureShortcut` is a Codable core value containing a supported key and a
normalized modifier set. App settings persist it in `UserDefaults`. The menu
bar exposes presets rather than an unrestricted key recorder in v0.1:
`⇧⌘2`, `⌥⌘2`, and `⌃⇧2`. Changing the preset replaces both local and global
event monitors and updates visible shortcut labels.

## Selection

The first drag creates a selection but does not immediately complete. Eight
handles allow resizing; dragging inside moves the selection. Return or double
click confirms, Escape cancels, and a small on-screen hint makes this
discoverable. A pixel loupe follows the pointer near the selection and samples
the frozen display image.

Handle hit testing and resize geometry live in KiriCore so every edge case is
unit tested independently of AppKit.

## Displays and reliability

Capture remains scoped to the display beneath the pointer. Mapping uses the
display ID from `NSScreen`, while crop conversion uses actual image and overlay
dimensions instead of assuming a 2× Retina scale. Tests cover negative display
origins, displays above the primary display, reverse drags, edge clamping,
moving, and all eight resize handles.

No capture data leaves the Mac. Invalid selections remain editable instead of
writing an empty asset. Export failures keep the editor open when possible and
surface a recoverable message.
