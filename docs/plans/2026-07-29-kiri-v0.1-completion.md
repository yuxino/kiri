# kiri v0.1 Completion Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Finish kiri's still-capture milestone with text and mosaic annotation, shortcut presets, adjustable selection, a pixel loupe, and tested multi-display geometry.

**Architecture:** Testable values and geometry live in KiriCore. AppKit views consume those values for drawing and event handling, while AppModel owns persistence and monitor replacement.

**Tech Stack:** Swift 6, AppKit, SwiftUI, ScreenCaptureKit, CoreGraphics, Swift Package Manager
