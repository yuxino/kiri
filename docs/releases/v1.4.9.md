## English

# Kiri v1.4.9

Kiri v1.4.9 completes the native macOS and Windows media pipelines and adds a
signed, user-initiated in-app updater.

## Highlights

- macOS recording, pause-segment merging, video thumbnails, and GIF export now
  use AVFoundation and ImageIO. Kiri no longer downloads or launches FFmpeg.
- Windows recording and GIF export use Media Foundation and system imaging
  components, with bounded capture and audio handoff queues.
- Settings now checks, downloads, verifies, and installs signed updates in
  separate user-confirmed steps. Download progress comes from actual bytes.
- macOS restarts only when **Restart and Finish Update** is clicked. Windows
  closes Kiri and hands installation to the passive NSIS installer.
- Windows capture startup, completion, OCR integration, multi-display geometry,
  and preview-window lifecycle received reliability fixes since v1.4.7.

## First updater installation

v1.4.9 is the first release containing the signed updater. v1.4.8 and older
builds must install v1.4.9 once from GitHub Releases. Future compatible releases
can then be installed from Settings.

Kiri still performs no background update checks, analytics, uploads, or silent
installation. Existing local libraries remain compatible.

## 中文

Kiri v1.4.9 完成 macOS 与 Windows 原生媒体链路，并加入由用户主动操作的签名应用内更新。

- macOS 录屏、暂停片段合并、视频缩略图和 GIF 导出使用 AVFoundation 与 ImageIO，不再下载或启动 FFmpeg。
- Windows 录屏和 GIF 导出使用 Media Foundation 与系统图像组件，捕获及音频队列均设上限。
- 设置中按独立确认步骤检查、下载、验证和安装签名更新，下载进度来自实际字节数。
- macOS 仅在点击“重启并完成更新”后重启；Windows 关闭 Kiri 并交给被动式 NSIS 安装器。
- 修复自 v1.4.7 以来 Windows 捕获启动、完成反馈、OCR、多显示器几何和预览窗口生命周期问题。

v1.4.9 是首个含签名更新器的版本，v1.4.8 及更旧版本必须先从 GitHub Releases 手动安装一次，之后可在设置中安装兼容更新。

不进行后台更新检查、分析统计、上传或静默安装，已有本地素材库保持兼容。
