## English

This update refreshes the Windows installer and makes in-app updates clearer on macOS and Windows.

- The Windows installer uses Kiri's half-body character artwork, sharper image scaling, and a more balanced layout. Welcome, installation, and completion pages support English, Simplified Chinese, and Japanese.
- The Windows tray uses Kiri's character icon. Installer previews now also display the application's own window icon.
- In **Settings → About → Check for Updates**, download progress is followed by signature verification. Windows explicitly offers **Install and Restart** and reopens Kiri after the update; macOS keeps installation and restart as separate actions.

Version 1.4.9 and later can update inside Kiri; older versions require one manual installer download. Downloads cover macOS 14+ on Apple silicon and Intel with one Universal DMG, and Windows 11 x64.

macOS retains the existing local signing identity and is not Apple-notarized. Windows installers are not Authenticode-signed. Automated checks and package verification do not replace full cross-version installation testing on users' devices.

## 中文

本次更新调整了 Windows 安装界面，并让 macOS 和 Windows 的应用内更新步骤更清楚。

- Windows 安装程序换上 Kiri 的半身立绘，改进图片缩放清晰度与整体排版。欢迎、安装和完成页面支持英文、简体中文和日文。
- Windows 托盘使用 Kiri 的角色图标，安装预览的窗口图标也与应用保持一致。
- 在“设置 → 关于 → 检查更新”中，下载进度结束后会显示签名校验。Windows 明确提供“安装并重启”，更新后重新打开 Kiri；macOS 的安装与重启仍由用户分别点击。

v1.4.9 及以后可直接在 Kiri 内更新，更旧版本需要先手动安装一次。提供 macOS 14+ Apple 芯片与 Intel 共用的 Universal DMG，以及 Windows 11 x64 安装包。

macOS 沿用现有本地签名，未经 Apple 公证；Windows 安装包未做 Authenticode 签名。自动检查与安装包核验不能替代用户设备上的完整跨版本安装测试。
