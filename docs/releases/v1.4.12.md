## English

# Kiri v1.4.12

## Media history fixes

- Retry previously failed previews after screenshot edits or missing-file recovery while preserving names being typed in cards.
- Prevent old file-check results from overwriting newer content or updating removed cards. Retry controls recover after either success or failure.
- Reflect committed removal of missing records even if auxiliary-file cleanup fails, while retaining the cleanup error message.

Remove an inactive macOS activation helper while retaining the Windows path so strict static checks pass.

## Downloads and updates

- macOS 14+: Universal DMG and signed in-app update archive for Apple silicon and Intel.
- Windows 11 x64: NSIS installer and updater signature.
- Version 1.4.9 and later can manually check, download, and install in Settings; older versions require one manual installation.

macOS retains its local signing identity without Apple notarization. If first launch is blocked, Control-click the app and choose Open, or use Open Anyway in System Settings. Windows installers lack Authenticode signing and may trigger SmartScreen.

## Verification scope

Automated regressions cover failed-preview recovery, stale requests, retries, card removal, and deletion commits with cleanup failures in a temporary media library. Full capture workflows, mixed-scale displays, and pause/resume acceptance on user devices remain separate. Isolated component tests do not establish native UI or installation acceptance.

## 中文

# Kiri v1.4.12

## 媒体历史修复

- 编辑截图或恢复缺失文件后，曾经加载失败的预览会重新加载；卡片中正在输入的名称会保留。
- 旧的文件检查结果不再覆盖新内容，也不会在卡片已移除后重新写入状态。预览重试成功或失败后，按钮都能恢复操作。
- 移除缺失记录时，即使附属文件清理失败，历史列表也会反映已经完成的记录删除，并保留清理失败提示。

本次还清理了已停用的 macOS 激活函数，保留 Windows 调用路径，使严格静态检查通过。

## 下载与更新

- macOS 14+：Apple 芯片与 Intel 共用一个 Universal DMG，以及签名的应用内更新归档。
- Windows 11 x64：NSIS 安装包及更新签名。
- v1.4.9 及以后可在设置中手动检查、下载和安装更新；更旧版本请先手动安装本版本。

macOS 沿用现有本地签名身份，未经过 Apple 公证。如系统拦截首次打开，请 Control-click 应用后选择 Open，或使用系统设置中的 Open Anyway。Windows 安装包未经过 Authenticode 签名，SmartScreen 可能提示警告。

## 验证范围

自动回归覆盖预览失败恢复、过期请求、重试、卡片移除，以及临时媒体库的删除提交与清理失败。完整捕获流程、混合缩放显示器和暂停/恢复的用户设备验收仍单独跟进；本次不将隔离组件测试作为原生界面或安装验收。
