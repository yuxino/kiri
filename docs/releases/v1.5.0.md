## English

## What's new

- Text History lets you search, revisit, and copy OCR results, with the source image available on demand.
- Run local OCR on saved screenshots from the library menu, image viewer, or editor.
- Recognized text and an independent image snapshot stay in your local library, support Trash recovery, and move with the library.

## Downloads

- macOS 14+: Universal DMG for Apple Silicon and Intel.
- Windows 11: x64 installer.

Version 1.4.9 and later can check for updates manually in Settings; older versions require a manual installer download. macOS retains the existing local signing identity and is not Apple-notarized. Windows installers are not Authenticode-signed.

## 中文

## 新功能

- 新增「文字」历史：搜索、回看和复制 OCR 结果，需要时展开或打开原图。
- 历史截图也能识别文字：从素材菜单、图片查看器或编辑器启动本地 OCR。
- 识别文字与独立原图快照保存在本地；删除后可从回收站恢复，也会随素材库迁移。



### 下载

macOS 14+：Apple 芯片与 Intel 共用 Universal DMG；Windows 11：x64 安装包。

v1.4.9 及以后可在设置中手动检查更新；更旧版本请手动下载安装包。macOS 沿用现有本地签名，未经过 Apple 公证；Windows 安装包未经过 Authenticode 签名。
