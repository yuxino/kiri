## English

- Add a Windows x64 Portable package. Download the `Portable.zip`, extract it, and run `kiri.exe` directly without using the installer.
- Keep the existing Windows NSIS installer and signed in-app updater artifacts unchanged.

The Portable package is intended for users who prefer an extract-and-run build. Like the Windows installer, it is not Authenticode-signed.

---

## 中文

- 新增 Windows x64 绿色版（Portable）。下载 `Portable.zip` 后解压，直接运行 `kiri.exe`，无需安装。
- 保留现有 Windows NSIS 安装包和应用内更新签名产物，不改变原有安装与更新流程。

绿色版适合希望解压即用的用户。与 Windows 安装包一样，目前未做 Authenticode 签名。
