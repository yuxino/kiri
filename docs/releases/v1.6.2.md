## English

- Fix capture overlays remaining invisible when another application is full screen on a macOS display, including secondary displays. Kiri now keeps its capture and feedback windows in the full-screen Space while retaining normal selection and keyboard handling.

The failure was reproduced on v1.6.1 and checked with the signed macOS app on system-level virtual secondary displays: right, left and above the primary, with 1×/2× scaling. Checks covered screenshot completion and clipboard pixels, native Escape, local OCR, recording export and repeated window cleanup. The original #21 report does not identify an operating system; physical Windows multi-display and Intel Mac acceptance remain unverified.

Version 1.4.9 and later can update through **Settings → About → Check for Updates**. Downloads include a Universal DMG for macOS 14+ on Apple silicon and Intel, and a Windows 11 x64 installer. macOS retains the existing local signing identity and is not Apple-notarized; first installation may require **Open Anyway** in Privacy & Security. Windows installers are not Authenticode-signed. Update downloads retain signature verification and separate user-controlled installation steps.

## 中文

- 修复 macOS 显示器（包括第二屏）运行其他应用的全屏窗口时，截图层已经创建却不可见的问题。截图和反馈窗口现在会出现在该全屏空间中，并保留正常框选和键盘操作。

已在 v1.6.1 复现故障，并使用正式签名的 macOS 应用，在系统级虚拟第二屏上验证修复，覆盖主屏右侧、左侧和上方布局以及 1×/2× 缩放。验证包括完成截图和剪贴板图片、原生 Escape、本地 OCR、录屏导出及连续开关窗口的清理。#21 原报告未注明操作系统；实体 Windows 多屏和 Intel Mac 验收仍未完成。

v1.4.9 及以后可通过“设置 → 关于 → 检查更新”升级。提供 macOS 14+ Apple 芯片与 Intel 共用的 Universal DMG，以及 Windows 11 x64 安装包。macOS 沿用现有本地签名，未经 Apple 公证；首次安装可能需要在“隐私与安全性”中点击“仍要打开”。Windows 安装包未做 Authenticode 签名。应用内更新保留下载签名校验和由用户分别操作的安装步骤。
