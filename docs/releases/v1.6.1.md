## English

- Change the global capture shortcut in **Settings → General**, including when the default combination is occupied. Choose Control, Alt/Option, or Command/Windows with a letter or number; Shift is optional. The choice persists after restarting Kiri, and Restore Default returns to Shift+Command+A on macOS or Shift+Ctrl+A on Windows.
- macOS now requests exclusive native hotkey registration, so a conflicting shortcut no longer incorrectly appears enabled. If a replacement cannot be registered or saved, Kiri keeps the previous choice and shows an error.

Native macOS checks covered shortcut conflicts, replacement, restart persistence, and capture triggering. System-level virtual second displays exercised positive and negative positions, 1×/2× scaling, screenshot completion, local OCR, and recording with pause/resume. The second-display failure reported in #21 was not reproduced in these configurations and remains open. Windows native capture/recording checks passed on hosted CI; physical multi-monitor Windows and Intel Mac acceptance remain unverified.

Version 1.4.9 and later can update through **Settings → About → Check for Updates**. Downloads include a Universal DMG for macOS 14+ on Apple silicon and Intel, and a Windows 11 x64 installer. macOS retains the existing local signing identity and is not Apple-notarized; first installation may require **Open Anyway** in Privacy & Security. Windows installers are not Authenticode-signed. Update downloads retain signature verification and separate user-controlled installation steps.

## 中文

- 可在“设置 → 通用”中修改全局截图快捷键，默认组合被占用时也能修改。支持 Control、Alt/Option 或 Command/Windows 搭配字母或数字，可选加 Shift。设置在重启后保留；恢复默认会回到 macOS 的 Shift+Command+A 或 Windows 的 Shift+Ctrl+A。
- macOS 改为独占注册系统快捷键，避免组合冲突时仍错误地显示“已启用”。新组合注册或保存失败时保留原设置，并显示错误提示。

macOS 原生验证覆盖快捷键冲突、修改、重启保存和实际触发截屏。系统级虚拟第二屏覆盖正负坐标、1×/2× 缩放、完成截图、本地 OCR，以及录屏和暂停恢复。#21 报告的第二屏故障在这些配置下尚未复现，因此继续保留开放。Windows 原生截屏和录屏检查已通过远程 CI；实体 Windows 多屏和 Intel Mac 验收仍未完成。

v1.4.9 及以后可通过“设置 → 关于 → 检查更新”升级。提供 macOS 14+ Apple 芯片与 Intel 共用的 Universal DMG，以及 Windows 11 x64 安装包。macOS 沿用现有本地签名，未经 Apple 公证；首次安装可能需要在“隐私与安全性”中点击“仍要打开”。Windows 安装包未做 Authenticode 签名。应用内更新保留下载签名校验和由用户分别操作的安装步骤。
