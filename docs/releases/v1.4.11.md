## English

# Kiri v1.4.11

## Fixes

- Fix capture overlays appearing in a different Space when Kiri's global shortcut is used over a browser or player in native macOS fullscreen.
- Keep the overlay above the current fullscreen Space without switching back to Kiri. Clicking the overlay remains interactive.
- Retain the Windows topmost-and-focus path. No equivalent issue was found; Windows regressions, compilation, and real desktop recording-control checks passed.

## Improvements

- Prevent stale thumbnails from reentering the cache after edits, deletion, or migration by coordinating preview generation and invalidation.
- Release duplicate remote OCR image data earlier to reduce memory use while waiting for responses.
- Remove duplicate translation and image-decoding functionality from release packages while retaining all three UI languages and capture formats.
- Center the video, description, and watch links in multilingual README demos while retaining existing assets.

## Included from v1.4.10

- Run OCR on the full selection after mouse release, avoiding premature recognition of a small region during dragging.
- Compact black countdown and recording-control state synchronization fixes.
- Updated full demo with a larger OCR region, more recognized content, and a longer ending.

Updates remain user initiated in Settings, with no background checks or silent installation.

## Downloads and verification

- macOS 14+: Universal DMG and signed update archive for Apple silicon and Intel.
- Windows 11 x64: NSIS installer and updater signature, with the new installer UI.
- Version 1.4.9 and later can check manually in Settings; older versions require one manual installation.

macOS retains its local signing identity without Apple notarization; use the supported manual-open flow if blocked. Windows installers lack Authenticode signing and may trigger SmartScreen.

Automated checks cover both macOS architectures, Windows regressions and builds, and countdown/recording-control windows. Full capture workflows, mixed-scale displays, and pause/resume acceptance on user devices remain separate follow-up work.

## 中文

# Kiri v1.4.11

## 修复

- 修复 macOS 在浏览器或播放器进入原生全屏后，按 Kiri 全局快捷键时截图层可能出现在其他 Space、看起来像没有触发的问题。
- 截图层现在会留在当前全屏 Space 上方显示，不再为了显示截图层切换回 Kiri；点击截图层后仍可正常交互。
- Windows 继续使用原有的置顶 + 聚焦路径；本次没有发现同类问题，并通过 Windows 回归、编译和实际桌面录制控制检查。

## 本轮优化

- 修复素材编辑、删除或迁移后，旧缩略图可能重新进入缓存的问题，统一预览生成与失效同步。
- 提前释放远程 OCR 的重复图像数据，减少等待响应期间的内存占用。
- 精简发布包中的重复翻译与图像解码功能，保留三种界面语言及现有捕获格式。
- 多语言 README 演示按视频、描述、观看链接居中排列，保留原有资源。

## 继续包含 v1.4.10 的改进

- OCR 等待鼠标松开后再按完整选区识别，避免拖选中途提前识别小框。
- 紧凑黑色录屏倒计时与录制控制状态同步修复。
- 完整演示更新：更大的 OCR 区域、更丰富的识别内容和更长的结尾停留。

Kiri 仍然不做后台更新检查或静默安装；更新由用户在设置中主动触发。

## 下载与验证边界

- macOS 14+：Apple 芯片与 Intel 共用一个 Universal DMG 和签名更新归档。
- Windows 11 x64：NSIS 安装包及更新签名，包含新版安装界面。
- v1.4.9 及以后可从设置中手动检查更新；更旧版本需先手动安装一次本版本。

macOS 沿用现有本地签名身份，未经过 Apple 公证；如系统提示拦截，请使用系统支持的手动打开方式。Windows 安装包未经过 Authenticode 签名，SmartScreen 可能提示警告。

自动检查覆盖 macOS 双架构构建、Windows 回归与构建，以及倒计时和录制控制窗口。完整捕获流程、混合缩放显示器和暂停/恢复的用户设备验收仍单独跟进。
