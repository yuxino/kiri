## English

# Kiri v1.4.10

## Changes

- Fix premature OCR during dragging: recognize the complete selection once after mouse release, and retain the selection when switching modes.
- Use a compact black recording countdown ring without a separate Cancel button. Clicking the ring or pressing Esc still cancels.
- Start the countdown only after the UI appears, fixing startup ordering and recording-control state synchronization.
- Use the shared light illustrated theme for the Windows installer.
- Update the full demo: remove the cancelled recording segment, enlarge the OCR selection, show more recognized text, and hold the ending longer.

## Installation and updates

Version 1.4.9 users can manually check and install signed updates in Settings. Earlier versions need one manual upgrade. The update flow, signing public key, library format, and recording cancellation remain unchanged.

The maintainer must package production macOS builds with the existing long-term signing identity, without substituting a temporary signature. Windows installers have updater signatures but no Authenticode signature. A draft may become public only after the corresponding platform artifacts and verification are complete.

## 中文

# Kiri v1.4.10

## 更新内容

- 修复 OCR 拖选中途提前识别的问题：松开鼠标后按完整选区识别一次，切换模式仍可复用已有选区。

- 录屏倒计时改为紧凑黑色圆环，不再显示单独的取消按钮；点击圆环或按 Esc 仍可取消。
- 倒计时在界面显示后才开始，修复启动时序和录制控制条的状态同步。
- Windows 安装程序采用统一的浅色插画主题。
- 更新完整演示：移除取消录制片段，扩大 OCR 选区、展示更多文字，延长结尾停留。

## 安装与更新

使用已有 v1.4.9 的用户可在设置中手动检查并安装签名更新。更早版本需先手动升级一次。更新方式、签名公钥、素材库格式和取消录制功能保持不变。

macOS 正式包必须由维护者使用原有长期签名身份打包，不用临时签名替代。Windows 安装包具有更新器签名，但没有 Authenticode 签名。发布草稿须等相应平台产物及验证齐备后再转为正式版本。
