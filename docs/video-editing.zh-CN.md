# 在 Kiri 中剪辑视频

[English](video-editing.md) · **简体中文**

从素材库打开视频，点击画面上方的「剪辑与导出」。本指南说明当前源码中的功能；你安装的版本有哪些操作，请以相应更新记录为准。

每个工程编辑一个源视频。可以将它分成多个片段并重新排序，但不能把导入的多个视频合成一条时间轴。

## 导入录屏或本地文件

Kiri 录屏会保存在素材库中。其他文件可通过「导入素材」添加，也可以将 PNG、JPEG、WebP、MP4 或 MOV 文件拖入素材库。导入的图片使用图片编辑器，视频使用视频编辑器。

导入后保留原文件名，清除筛选后显示在素材库顶部。图片会校正方向并转换为 PNG，视频复制到素材库，原文件不受影响。每次最多导入 32 个文件；图片不能超过 32 MB、每边 8192 像素，并须符合解码内存限制；视频上限为 8 GB。

## 裁剪与调整片段

- 点击时间轴定位，拖动片段两端裁剪，也可以在播放头处分割、删除不要的片段，或拖动片段重新排序。
- 选中片段后可设置 0.25～4 倍速度，预览与导出均生效。
- 时间轴高度可以调整；轨道较多时在时间轴内部滚动，为画面留出空间。
- 裁剪、排序、变速、效果、标注和时间调整均支持撤销、重做。删除操作作用于当前选中的片段、标注、贴图或效果。

播放控件位于画面外，进度条支持键盘调整和悬停时间提示。拖动时暂停，松手恢复此前的播放状态。播放速度可选预设或输入 0.1～8 倍，并会记住偏好；它只影响观看，不改变导出速度。

## 添加标注、贴图和效果

剪辑器显示截图中的画笔、矩形、直线、箭头、可编辑文字，以及像素和模糊马赛克笔刷。工具沿用已保存的外观设置，首次使用时默认红色。视频马赛克支持自由涂抹、矩形和椭圆覆盖。

画完后会选中新标注。可在属性区修改颜色、粗细或马赛克设置，拖动画面上的手柄调整形状。点击「编辑文字」修改内容；字号、颜色和背景实时生效，文字轨道显示实际内容。Esc 取消当前文字编辑。

工具栏可以添加本地 PNG、JPEG 或 WebP 静态贴图。贴图保留透明背景，缩放时保持比例。标注、贴图和遮挡都可以直接在画面中选中并拖动。

效果包括按时段设置的 1.5～4 倍局部放大，可调整进入和退出时长；隐私遮挡可选模糊、像素或自定义颜色的纯色。放大后可以拖动画面调整取景。还可添加聚光强调、保持比例的裁切与背景留白，以及可调时长和颜色的淡入淡出。较少用的选项收在「画面修饰」中，修改结果直接显示在画面上。

每个标注、贴图和效果都有独立时段。拖轨道中间移动时间，拖两端调整时长，拖左侧手柄上下调整图层顺序；接近列表边缘时会自动滚动。上方叠加内容盖住下方内容，预览与导出一致；整幅画面的调整在单独一组中排序。时段说明随裁剪、变速更新，与成片时间轴一致。

## 保存并继续编辑

剪辑、效果轨道、贴图和当前位置会自动保存到本地素材库。重新打开原片即可继续，也可以按 Cmd/Ctrl+S 立即保存。关闭窗口时会提交当前文字编辑并等待保存；保存失败时可以重试或继续编辑。明确选择不保存并关闭时，会保留最后一次成功保存的工程。

可编辑工程与导出的 MP4 分开保存，导出不会替换原片。

## 导出 MP4

点击右上角的「导出」。画质菜单会显示实际输出尺寸：

| 设置 | 输出尺寸 |
| --- | --- |
| 高画质 | 保留原始尺寸 |
| 日常分享 | 最长边不超过 1080 像素 |
| 小文件 | 最长边不超过 720 像素 |

不会放大小尺寸素材。文件大小取决于原片和编辑后的时长。导出会在素材库中创建新副本，显示编码进度，并可在最后保存到素材库之前取消。取消会保留工程，不会向素材库添加半成品。

导出保留同步声音。macOS 片段变速保持音调，Windows 变速会同时改变音调。Windows 的画面效果目前要求源视频不含旋转标记，Kiri 录屏符合此条件。
