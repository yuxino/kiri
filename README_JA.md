`kiri` の名前は、日本語の「切り取り」に由来します。

スクリーンショットの撮影、注釈、文字認識、範囲録画を行い、ローカルライブラリに保存します。クラウドアカウントは不要で、任意のリモート OCR はユーザーが明示的に操作した場合のみ使用されます。

## インターフェース

ライブラリ、復元可能なゴミ箱、フィルター、設定を、コンパクトなローカル
ワークスペースにまとめています。キャプチャ完了後の画像や録画には Kiri の
オーバーレイやコントロールは含まれません。

## 機能

- **スクリーンショット** — ウインドウのクリック選択または範囲ドラッグで正確に切り取れます。
- **注釈** — ペン、図形、矢印、テキスト、モザイクに対応し、元に戻す / やり直しも可能。追加済みの注釈は再選択して編集できます。
- **OCR** — 既定ではローカル文字認識(macOS Vision / Windows.Media.Ocr)。任意で Alibaba Cloud、OpenAI、または画像入力に対応し OpenAI Chat Completions API を実装する互換サービスのプロファイルを複数保存できます。リモート送信は画像ごとに「送信」または「再試行」を明示的に選んだ場合だけ行われ、失敗後に自動で再試行、サービス変更、代替アップロードされることはありません。
- **録画** — システム音声、マイク、ポインター、クリック表示を任意で含む範囲録画。3・2・1 カウントダウン、ドラッグ可能なコントロールバー(Esc で停止)、Retina 品質の MP4 出力。
- **GIF** — GIF として直接録画するか、長さを問わず既存の録画を 12 fps・長辺 720 px・無音のループ GIF に変換できます。直接生成に失敗した場合は、有効な MP4 を残します。
- **ライブラリ** — 日付ごとにグループ化されたキャプチャ。お気に入り、タグ、名前変更、検索、コピー、ファイル表示、復元可能なゴミ箱に対応。サイドバーとフィルターバーで種類・お気に入り・タグによる絞り込みができます。

## ダウンロード

最新ビルドは GitHub Releases からダウンロードできます。

- **macOS 14 以降**:Apple Silicon(`arm64`)または Intel(`x64`)用の `.dmg` を選んで開き、`Kiri.app` を「アプリケーション」フォルダへドラッグします。キャプチャには「画面とシステム音声の録画」権限が必要です。録画でクリック表示を有効にした場合のみ「入力監視」、マイク録音を有効にした場合のみ「マイク」権限も必要です。自分で書き出すか、現在の OCR 選択範囲を設定済みサービスへ明示的に送信しない限り、キャプチャは Mac 上に留まります。
- **Windows**:画面キャプチャの権限は不要です。マイク録音を有効にした場合、アクセスは Windows のプライバシー設定で管理されます。

GitHub 配布版は ad-hoc 署名のため、初回起動時に Gatekeeper が止める場合があります。`Kiri.app` を Control クリックして「開く」を選ぶか、システム設定 → プライバシーとセキュリティ →「このまま開く」を使用してください。Gatekeeper を無効にする必要はありません。

リモート OCR は任意です。API キーは macOS キーチェーンまたは Windows
資格情報マネージャーに保存され、プロファイル JSON には書き込まれません。
ローカル OCR が常に初期設定で、プロファイルの作成や選択だけでは画像は送信
されません。

録画と GIF 変換には FFmpeg を使用します。利用可能なコピーがない場合、初回録画
または明示的な GIF 変換時に一度だけダウンロードし、OS のキャッシュへ保存します。
ライブラリの閲覧だけではダウンロードしません。この依存関係のダウンロードに
スクリーンショット、録画、ライブラリ、アカウント情報は含まれません。

## ソースからビルド

Rust 1.88+、Node.js 20.19+（または 22.12+）、pnpm が必要です。

```bash
git clone https://github.com/yuxino/kiri.git
cd kiri
pnpm install
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build --no-bundle   # または ./scripts/package-app.sh でインストーラを生成
```

> 注意:素の `cargo build` で生成したバイナリは空白ウインドウになります。
> フロントエンドのアセットは `pnpm tauri build` で埋め込まれ、`pnpm
> tauri dev` では Vite から配信されます。

macOS のパッケージングには Xcode コマンドライン・ツールも必要です。

## ショートカット

- **⇧⌘A**(macOS)/ **Shift+Ctrl+A**(Windows)— Kiri を開く
- **Esc** — キャプチャをキャンセル
- **Return** — キャプチャをコピー
- **V** — 注釈の選択 / 移動
- **P / R / L / A / T / M** — ペン / 四角形 / 直線 / 矢印 / テキスト / モザイク
- **Delete** — 選択中の注釈を削除
- **Esc**(録画中)— 停止
- **⌘F**(macOS)/ **Ctrl+F**(Windows)— ライブラリを検索
- **⌘Z / ⇧⌘Z**(macOS)/ **Ctrl+Z / Shift+Ctrl+Z**(Windows)— 元に戻す / やり直す
