`kiri` の名前は、日本語の「切り取り」に由来します。

画面の一部を一回の操作でコピーし、必要なときだけ注釈を加えられるネイティブ macOS
アプリです。完成したキャプチャはローカルライブラリにも自動保存されるため、
クリップボードを書き換えたあとでも見つけ直せます。

## 現在できること

- Kiri が先に受け取る **⇧⌘A** でキャプチャを開始し、他アプリの同時動作を防止
- 画面を静止し、最前面のウインドウへ吸着、または移動・8 方向リサイズ可能な範囲を選択
- 範囲を描くとツールバーがすぐに表示され、ツール選択までは移動・8 方向リサイズが可能
- ペン、四角形、直線、矢印、テキスト、連続ブラシ式モザイク、元に戻す、やり直し
- 既定のポインタで既存テキストを選択・移動し、ダブルクリックで再編集
- ペンとモザイクの移動、四角形の 8 方向リサイズ、直線・矢印の端点調整、Delete 削除に対応
- ペン幅、図形の線幅、文字サイズ、モザイクブラシを数値付きの連続スライダーで調整し、入力中や再編集後の文字サイズ変更にも対応
- モザイクは弱・標準・強のピクセル強度に対応
- 8 色の注釈カラーと、透明（既定）、濃色、淡色のテキスト背景
- 日本語入力と長いテキストに対応し、プレビューと書き出しの改行位置を統一
- どの段階でも Esc でキャンセルし、範囲表示後は Return ですぐコピー
- 通常のスクリーンショットはクリップボードへコピーして元のアプリへ戻り、Kiri ライブラリを自動表示しない
- 必要に応じて保存、ピン留め、フルエディタを選択
- キャプチャ開始時の第 1 階層でスクリーンショットまたは録画を選択
- 録画前に 3 秒カウントダウン、システム音声、マイク、ポインター、クリック表示を切り替え
- Esc で 3・2・1 をキャンセルし、H.264 MP4 を保存して 15 秒以内の動画をループ GIF へ変換
- 表示されたコントロールバーから一時停止、再開、停止し、一時停止時間を動画から除外
- 録画はバックグラウンドで保存して元のアプリへ戻り、ライブラリは必要なときだけ開く
- 完成したキャプチャは一度だけ保存され、履歴へ自動追加
- ライブラリ内の検索、お気に入り、再コピー
- 各ライブラリカードから直接ゴミ箱へ移動し、復元または完全削除
- 元アプリ、画像サイズ、種類、作成日時を記録
- 起動中は Dock アイコンとメニューバーの入口を両方表示

> kiri は現在、ソースコードのアーリープレビューです。音声とポインター表示を含む
> 範囲録画、短い動画の GIF 書き出しは v0.2 プレビューで利用でき、停止・再開、
> トリミング、スクロールキャプチャは引き続き開発中です。

## ダウンロード

[GitHub Releases](https://github.com/yuxino/kiri/releases/latest) から
`Kiri-v0.1.0-macos.zip` をダウンロードし、展開した `Kiri.app` を
「アプリケーション」フォルダへ移動してください。

v0.1.0 は Apple の公証をまだ受けていないアーリープレビューです。初回起動時は Finder で
Kiri を Control クリックし、「開く」を選んで確認する必要がある場合があります。
必ず本リポジトリの Releases ページからダウンロードしてください。

## ソースから実行

macOS 14 以降と Swift 6 が必要です。

```bash
git clone https://github.com/yuxino/kiri.git
cd kiri
swift run kiri-core-tests
./scripts/install-app.sh
open /Applications/Kiri.app
```

インストーラは常に `/Applications/Kiri.app` に固定パスで配置します。この正式版だけを
起動してください。更新時は実行中の Kiri を先に終了し、同じ bundle ID の古いコピーも
Kiri が自動終了するため、macOS の権限が
一つのアプリに安定して紐づきます。

パッケージスクリプトは Apple Development、Developer ID、または Kiri の安定した
ローカル証明書を優先し、画面収録権限を壊す一時署名へ暗黙に切り替えません。
`KIRI_CODESIGN_IDENTITY="証明書名"` で明示的に指定できます。
`KIRI_ALLOW_ADHOC_SIGNING=1` は権限を保持しなくてよい使い捨てビルド専用です。

## キャプチャのショートカット

- **⇧⌘A**：システム全体で Kiri のキャプチャを開始し、このキーを排他的に使用
- **Esc**：範囲選択、注釈、テキスト入力のどの段階でもキャンセル
- **Return**：編集中のテキストを確定してキャプチャをコピー
- **V**：既存注釈の選択・移動・変形。テキストはダブルクリックで再編集
- **P / R / L / A / T / M**：ペン、四角形、直線、矢印、テキスト、モザイク
- **Delete**：ポインターツールで選択中の注釈を削除
- **⌘Z / ⇧⌘Z**：元に戻す / やり直す

排他的ショートカットには入力監視、最初のキャプチャには画面収録権限が必要です。Kiri は起動ごとに
システムの権限要求を一度だけ行い、それ以降は設定を開く、または kiri を終了する
操作を表示して、同じダイアログを繰り返しません。データは
`~/Library/Application Support/kiri/` に保存され、自動で外部へ送信されません。

## 範囲録画と GIF（v0.2 プレビュー）

1. **⇧⌘A** を押して録画範囲を選択します。
2. 最初に表示されるモード選択で **Record** を選び、録画範囲を指定します。
3. 自動表示される設定でカウントダウン、システム音声、マイク、ポインター、クリック表示を設定します。
4. **Start Recording** を選びます。3・2・1 の途中は Esc でキャンセルできます。
5. フローティングバー、Kiri メニュー、または「Capture」メニューから一時停止、再開、停止します。
6. MP4 はライブラリへ入り、15 秒以内なら **Convert to GIF** を利用できます。

音声は既定でオフになり、マイクを有効にした場合だけ権限を要求します。マイク録音と
システム標準のクリック表示には macOS 15 以降が必要です。
