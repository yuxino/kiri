> **注記:** 再編集可能なスクリーンショット注釈、トリミング、注釈スタイルの記憶は現在の `main` に含まれますが、v1.4.4 のダウンロードにはまだ含まれていません。

`kiri` の名前は、日本語の「切り取り」に由来します。

スクリーンショット、注釈、文字認識、範囲録画を行い、ローカルライブラリに保存します。クラウドアカウントは不要で、リモート OCR は明示的に送信した場合だけ使用します。

## インターフェース

ライブラリ、復元可能なゴミ箱、フィルター、設定を一つのコンパクトなワークスペースにまとめています。完成した画像や録画には Kiri のオーバーレイやコントロールは含まれません。

## 機能

- **スクリーンショット** — ウインドウをクリックするか範囲をドラッグして切り取れます。
- **トリミングと注釈** — トリミング、ペン、図形、矢印、テキスト、モザイク、元に戻す / やり直すに対応します。色、線幅、テキスト、モザイクのスタイルは前回の選択を引き継ぎます。現在の `main` で作成した注釈は、完了カードまたはライブラリから開き直して編集できます。
- **OCR** — 既定では macOS Vision または Windows.Media.Ocr でローカル認識します。任意のリモート OCR は送信のたびに確認します。
- **録画** — システム音声、マイク、ポインター、クリック表示を任意で含む範囲録画を、Retina 品質の MP4 で保存します。
- **GIF** — GIF として直接録画するか、既存の録画を無音のループ GIF に変換できます。失敗時は有効な MP4 を残します。
- **ライブラリ** — お気に入り、タグ、名前変更、検索、コピー、ファイル表示、復元可能なゴミ箱に対応します。別のローカルフォルダや外付けディスクを保存先にできます。

ライブラリがオフラインの場合は、再試行または再指定できます。見つからない素材はファイルを選んで補完でき、読み込めなかった録画は再試行用に保持されます。

> このライブラリ機能は `main` に含まれています。現在の v1.4.4 ダウンロードにはまだ含まれていません。

## ダウンロード

最新ビルドは [GitHub Releases](https://github.com/yuxino/kiri/releases/latest) からダウンロードできます。

- **macOS 14 以降**: Apple Silicon（`arm64`）または Intel（`x64`）版の `.dmg` を開き、`Kiri.app` を「アプリケーション」へドラッグします。キャプチャには「画面とシステム音声の録画」が必要で、「入力監視」はクリック表示を使う場合のみ必要です。マイク録音には macOS 15 以降と「マイク」権限が必要です。
- **Windows**: 画面キャプチャに追加権限は不要で、マイクは Windows のプライバシー設定に従います。インストーラーは Authenticode 署名されておらず、Windows の実機検証も未完了です。

現在の v1.4.4 macOS 版は、プロジェクトが管理するローカルの自己署名 ID を使用しています。Developer ID 署名や Apple 公証ではないため、Gatekeeper が初回起動を止める場合があります。その場合は Control クリックから「開く」、または「プライバシーとセキュリティ」の「このまま開く」を使用してください。

macOS DMG は管理者が信頼できる Mac で作成して Release に添付し、GitHub Actions は Windows draft を生成します。署名 ID が変わると、macOS が関連権限を再度求める場合があります。

リモート OCR は任意です。API キーは macOS キーチェーンまたは Windows 資格情報マネージャーに保存され、画像は明示的に送信した場合だけ外部へ送られます。現在の `main` では、共有用の統合済み画像に加え、注釈前の元画像と注釈ドキュメントもローカルに保存します。モザイクで覆っても元画像の画素は削除されませんが、トリミングを保存すると範囲外の画素は元画像からも削除されます。編集機能がこれらをアップロードすることはありません。

録画と GIF 変換には FFmpeg を使用します。利用可能なコピーがない場合、初回録画または手動 GIF 変換時にダウンロードしてキャッシュし、ライブラリ閲覧だけではダウンロードしません。

## ソースからビルド

Rust 1.88+、Node.js 20.19+（または 22.12+）、pnpm が必要です。

```bash
git clone https://github.com/yuxino/kiri.git
cd kiri
pnpm install
cargo test --manifest-path src-tauri/Cargo.toml
pnpm tauri build --no-bundle   # または ./scripts/package-app.sh でインストーラを生成
```

> 注意: 通常の `cargo build` で生成した実行ファイルにはフロントエンド資産が含まれません。
> 開発時は `pnpm tauri dev`、ビルド時は `pnpm tauri build` を使用してください。

macOS のパッケージングには Xcode Command Line Tools と安定した署名 ID も必要です。

## ショートカット

- **⇧⌘A** (macOS) / **Shift+Ctrl+A** (Windows) — Kiri を開く
- **Esc** — キャプチャをキャンセル
- **Return** — キャプチャをコピー
- **V** — 注釈の選択 / 移動
- **C** — スクリーンショット編集時のトリミング
- **P / R / L / A / T / M** — ペン / 四角形 / 直線 / 矢印 / テキスト / モザイク
- **Delete** — 選択中の注釈を削除
- **Esc** (録画中) — 停止
- **⌘F** (macOS) / **Ctrl+F** (Windows) — ライブラリを検索
- **⌘Z / ⇧⌘Z** (macOS) / **Ctrl+Z / Shift+Ctrl+Z** (Windows) — 元に戻す / やり直す
